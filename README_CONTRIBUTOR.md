# 👨‍💻 Инструкция для участника команды

Пожалуйста, следуйте этому регламенту при внесении изменений в проект, чтобы избежать конфликтов и не сломать основной код.

---

## ⚠️ Главное правило
**Никогда не делайте коммиты напрямую в ветку `main`.** Все изменения вносятся только через создание отдельной ветки и Pull Request.

---

## Пошаговый алгоритм работы

### Step 1. Получение актуального кода
Перед началом работы над новой задачей обновите локальную ветку `main`:
```bash
git checkout main
git pull origin main
